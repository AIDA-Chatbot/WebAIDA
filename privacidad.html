Política de privacidad

AIDA es un asistente desarrollado por el equipo de AIDA Bot con el objetivo de acompañar y asistir a las personas en el uso de herramientas digitales. Esta política explica cómo recolectamos, usamos y protegemos los datos de quienes interactúan con el asistente.

Qué datos recopilamos

Durante el uso del asistente podemos recolectar:

  • Nombre o apodo (si la persona decide compartirlo)
  • Edad (si la persona decide compartirla)
  • Preferencias del usuario: idioma, tipo de voz, entre otras
  • Mensajes enviados en el chat
  • ID de usuario de Telegram, fecha y hora de cada interacción
  • Información técnica necesaria para el funcionamiento interno del sistema

Para qué usamos esta información

Utilizamos los datos exclusivamente para:

  • Mejorar la calidad de las respuestas del asistente
  • Personalizar la experiencia de cada usuario
  • Detectar errores y mejorar el funcionamiento
  • Brindar soporte técnico cuando sea necesario

No vendemos ni compartimos datos con terceros.

Dónde se almacenan los datos

Toda la información se almacena en Firebase (Google Cloud), que utiliza estándares de seguridad y cifrado a nivel de servidor. El acceso está restringido exclusivamente al equipo de AIDA.

Tus derechos

Podés en cualquier momento:

  • Solicitar acceso a tu información
  • Pedir la eliminación de tus datos
  • Consultar cómo se usa tu información

Para ejercer estos derechos, escribinos a aidaassistantbot@gmail.com.

Seguridad

Tomamos medidas razonables para proteger la información, incluyendo acceso restringido a administradores y almacenamiento en un entorno seguro provisto por Firebase. Ningún sistema es completamente infalible, por lo que recomendamos no compartir datos extremadamente sensibles como información bancaria o de salud detallada.

Cambios en esta política

Podemos actualizar esta política ocasionalmente. La fecha de última modificación estará siempre visible en la parte superior de esta sección.

Términos y condiciones

Naturaleza del servicio

AIDA es un asistente virtual diseñado para acompañar a personas en el uso de tecnología mediante explicaciones simples y amigables. AIDA no reemplaza profesionales humanos como médicos, abogados, psicólogos o técnicos certificados.

Uso permitido

Al usar AIDA, el usuario se compromete a:

  • No usar el asistente para actividades ilegales
  • No intentar acceder al código, servidores o datos de otros usuarios
  • No compartir contenido ofensivo, discriminatorio o inapropiado

Límites de responsabilidad

Aunque buscamos que AIDA sea preciso y útil, puede cometer errores. Las respuestas del asistente son orientativas. El equipo de AIDA no es responsable por decisiones tomadas basadas exclusivamente en la información proporcionada por el bot.

Modificaciones

Nos reservamos el derecho de actualizar o modificar estas condiciones cuando sea necesario. Los cambios se comunicarán a través de este mismo sitio.
